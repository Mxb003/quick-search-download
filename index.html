三步开始。

    下载并解压

  2. 2
    填写 API Key

    打开右上角设置，填入自己的 DeepSeek API Key。软件不会内置开发者 Key。

    开始学习

    输入框按 Enter 发送，使用截图热键框选需要提问的内容。

PRIVACY & CONTROL

你的 Key，你的记录。

本地保存

热键、历史和截图保存在本机。网站不收集你的搜索记录。

直接请求

文字和截图会从软件发送到你配置的 DeepSeek API，不经过本站服务器。

敏感内容

请不要上传密码、身份证、银行卡等不适合发送给 AI 服务的内容。

REMOVE QUICK SEARCH

需要卸载时，很简单。

软件包内已经包含 unQuickTranslate.exe。请在 QuickTranslate 所在文件夹中双击它，程序会关闭应用并清理本地配置、历史记录和自启动项。

⌫卸载程序随软件包提供请不要把它单独放进下载目录运行。
